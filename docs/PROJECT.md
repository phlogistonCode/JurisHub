# JurisHub — документация проекта

## Назначение

JurisHub — desktop-приложение на Kotlin Multiplatform с интерфейсом Compose. Основной сценарий — сравнение содержимого двух юридических документов с подсветкой отличий.

## Поддерживаемые форматы

- TXT — чтение текста напрямую.
- PDF — извлечение текста Apache PDFBox.
- DOC — извлечение текста Apache POI HWPF.
- DOCX — извлечение текста Apache POI XWPF.

Сравнение выполняется по строкам, словам или символам. Изменения в левом и правом документе подсвечиваются разными цветами.

## Структура репозитория

- `desktopApp/` — приложение Compose Desktop, JVM-интерфейс и работа с файловыми форматами.
- `desktopApp/src/main/kotlin/dev/phlogiston/jurishub/ui/` — desktop UI-компоненты.
  - `DesktopApp.kt` — корневой экран, состояние приложения, выбор файлов и запуск сравнения.
  - `DocumentChooser.kt` — отдельная карточка выбора документа.
  - `SideBySideDiffView.kt` — параллельный просмотр документов с подсветкой.
  - `SettingsScreen.kt` — параметры отображения и выбор шрифта.
  - `DocumentReader.kt` — извлечение и кэширование текста документов.
- `desktopApp/src/main/kotlin/dev/phlogiston/jurishub/core/` — логика сравнения.
  - `ComparisonMode.kt` — режимы сравнения и подписи для UI.
  - `InlineDiff.kt` — разбиение текста на токены, поиск изменений и подготовка Compose-разметки.
- `shared/` — общий KMP-модуль, предназначенный для кода, используемого платформами.
- `androidApp/` — Android-приложение.
- `iosApp/` — iOS-проект.
- `docs/` — документация проекта.

## Поток сравнения

1. Пользователь выбирает два файла в `DesktopApp`.
2. `DocumentReader` извлекает текст и кэширует его по пути и времени изменения файла.
3. `InlineDiff` сравнивает тексты в выбранном `ComparisonMode`.
4. `SideBySideDiffView` отображает версии рядом, с нумерацией строк и подсветкой отличий.

## Сборка и запуск

Команды Gradle запускаются из корня репозитория:

```shell
./gradlew :desktopApp:run
./gradlew :desktopApp:build
```

Сборка приложения требует JDK, совместимый с настройками проекта.

## Архитектурная заметка

`core/InlineDiff.kt` сейчас использует Compose `AnnotatedString` и `Color`, поэтому алгоритм сравнения связан с UI-библиотекой. Чтение PDF/DOC/DOCX и системный диалог выбора файлов относятся к JVM/Desktop и не должны напрямую переноситься в `shared/commonMain` без платформенной абстракции.
